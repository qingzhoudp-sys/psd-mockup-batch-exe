# PSD 样机智能对象批量替换

Windows 中文图形界面，通过本机 Adobe Photoshop 批量替换 PSD 中名为“样机”的智能对象，并同时或分别导出 JPG、PNG。

## 使用条件

- Windows 10/11
- Adobe Photoshop（建议 2021 或更高版本）
- PSD/PSB 中存在名为“样机”的智能对象图层

## 直接运行源码

1. 安装 Python 3.10 或更高版本，并勾选“Add Python to PATH”。
2. 双击 `安装依赖.bat`。
3. 双击 `启动程序.bat`。

## 生成 EXE

双击 `build_exe.bat`。完成后文件位于：

`dist\PSD样机批量替换.exe`

EXE 不需要安装 Python，但目标电脑仍需安装 Photoshop。

## 工作规则

- 支持 PNG、JPG/JPEG、TIF/TIFF、PSD 素材。
- 每个素材都重新打开一次原始样机，避免前一个素材影响后一个结果。
- 精确查找名为“样机”的智能对象，支持位于图层组中。
- 把素材写入智能对象内部，因此会保留样机已有的透视、变形、蒙版、混合模式、阴影和高光。
- 原始 PSD 不会被保存或覆盖。
- 输出名称为 `素材名_样机文件名.jpg/png`。
- 若输出文件已存在，会自动增加 `_2`、`_3` 等序号，不覆盖旧文件。
- 运行日志同时保存在输出目录的 `PSD样机批量替换_日志.txt`。

## 适配方式

- 填充画布：等比例铺满，超出部分裁切，适合大多数电商样机。
- 完整显示：等比例完整放入，可能留边。
- 拉伸铺满：强制匹配智能对象画布，可能变形。

## 常见问题

- 提示找不到 Photoshop：先正常启动一次 Photoshop，再运行本程序；仍失败时重新安装 Photoshop。
- 提示找不到“样机”：确认目标图层是智能对象，且图层名称完全是“样机”。
- Photoshop 弹出权限提示：允许脚本运行以及外部程序控制 Photoshop。
- 素材透明区域变黑：优先导出 PNG；JPG 不支持透明背景。
